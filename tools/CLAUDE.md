# tools/ — codegen configuration

The `*.rsp` files are the ClangSharp configuration that produces the `Generated/` directories — they are the thing to edit when bindings need to change (never the generated output):

- `generate.rsp` → `src/Ahjo.Vulkan.Native/Generated/` (from `vulkan.h`)
- `generate-vma.rsp` → `src/Ahjo.Vulkan.Vma.Native/Generated/` (from `vk_mem_alloc.h`; quirks documented in `generate-vma.notes.md`)
- `generate-ktx.rsp` → `src/Ahjo.Vulkan.Ktx.Native/Generated/` (from Khronos `ktx.h`)

Header versions are pinned in `Directory.Build.props` (`VulkanHeadersVersion`, `VmaVersion`, `KtxVersion`). Bump deliberately — generated bindings are committed, so every bump requires a regen run (`/regen-bindings`) and all packages ship under a single `v*` tag.

`Ahjo.Vulkan.StructExtendsGen/` and `Ahjo.Vulkan.ResultPolicyGen/` are in-repo generators that post-process the bindings (pNext-chain `IChainable` implementations, result-policy classification). Their output is also committed and regenerated by the same `-t:Regenerate` targets.
