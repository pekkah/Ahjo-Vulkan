# tools/ — codegen configuration

The `*.rsp` files are the ClangSharp configuration that produces the `Generated/` directories — they are the thing to edit when bindings need to change (never the generated output):

- `generate.rsp` → `src/Ahjo.Vulkan.Native/Generated/` (from `vulkan.h`)
- `generate-vma.rsp` → `src/Ahjo.Vulkan.Vma.Native/Generated/` (from `vk_mem_alloc.h`; quirks documented in `generate-vma.notes.md`)
- `generate-ktx.rsp` → `src/Ahjo.Vulkan.Ktx.Native/Generated/` (from Khronos `ktx.h`)
- `generate-slang.rsp` → `src/Ahjo.Vulkan.Slang.Native/Generated/` (from `slang.h` + `slang-deprecated.h`; C++ mode with vtables — read its header comments before touching it, especially the rule that **no virtual member may ever be `--exclude`d**, because that silently shifts every later vtable index)
- `generate-ngx.rsp` → `src/Ahjo.Vulkan.Ngx.Native/Generated/` (from `native/ngx/src/ahjo_ngx.h` + the pinned NGX headers; C mode; **the only rsp that turns `--generate macro-bindings` on and the only one that does not pass `--generate enum-member-type-name=false` — read its header comments before touching either**. Both deltas were forced by measured failures, not chosen for taste)

Header versions are pinned in `Directory.Build.props` (`VulkanHeadersVersion`, `VmaVersion`, `KtxVersion`, `SlangVersion`, `NgxVersion`). Slang additionally pins the SHA-256 of each prebuilt release archive, so its bump is version + both hashes. Bump deliberately — generated bindings are committed, so every bump requires a regen run (`/regen-bindings`) and all packages ship under a single `v*` tag.

`msbuild/Ahjo.Vulkan.SlangShaders.targets` is the shared shader build step (#171), imported by the repo-root `Directory.Build.targets` and inert without `SlangShader` items. It compiles each item with the pinned `slangc` from `native/slang/tool/<rid>/`: GLSL items (any extension but `.slang`) get entry `main`, output `%(Filename)%(Extension).spv` and `-matrix-layout-row-major`; `.slang` items need one item per entry point with `EntryPoint` and a required `OutputName`, and get no matrix flag. Errors: `AHJOSLANG001` compile failure (with slangc's text), `AHJOSLANG002` pinned slangc missing (unsupported host or `SkipSlangNativeFetch=true`), `AHJOSLANG003` `.slang` item without `OutputName`, `AHJOSLANG004` duplicate `OutputName`. Why it is shaped this way: `docs/design/specs/2026-11-06-issue-171-172-slang-shader-build-design.md`.

Two GLSL source rules the step cannot enforce with a flag, both measured on Slang 2026.19 and both pinned by `CompiledShaderTests`:

- **Every GLSL push-constant block says `std430`:** `layout(push_constant, std430) uniform …`. Slang's GLSL frontend lays push constants out std140 otherwise (glslc used std430), and no slangc option changes that — `-fvk-use-gl-layout` does not, and `-fvk-use-scalar-layout` is scalar, not std430. The difference is silent: `float arr[2]; float c;` puts `c` at 32 instead of 8.
- **A `local_size_x_id` workgroup size declares its default explicitly:** `layout(constant_id = N) const int k = 1;` next to `layout(local_size_x_id = N) in;`. A bare `local_size_x_id` defaults to 0 under Slang (glslc: 1), and adding `local_size_x = 1` to the same qualifier either keeps 0 or drops the spec constant, depending on order.

`Ahjo.Vulkan.StructExtendsGen/` and `Ahjo.Vulkan.ResultPolicyGen/` are in-repo generators that post-process the bindings (pNext-chain `IChainable` implementations, result-policy classification). Their output is also committed and regenerated by the same `-t:Regenerate` targets.
